## Engineering decision

Do not retry installation or diagnose an Apple firmware restriction from this
result. First locate the failure with a read-only Recovery diagnostic. The 31AL
companion retains the frozen collector, parser and admission predicates. A
generator verifies the old source hashes, adds observation marks and proves that
stripping those marks reproduces the exact original `state.c`. The other three
original C/header inputs are byte-identical. No pairing, Original Full Security,
target identity, no-follow or consistency predicate is relaxed.

The new CLI exposes only collection diagnosis, synthetic fixture diagnosis and
strict diagnostic validation. It cannot enroll, restore, select a default,
generate a transaction key or print the private snapshot. Its finite public
record names the stage, failure class, known reason and bounded command outcome.
It never returns raw policy text, identifiers, paths, unknown metadata values or
unknown-object hashes. A valid refusal is still a refusal; successful JSON
validation is not target admission or write authorization.

The shell distinguishes input binding, held work-directory binding, output-file
open, child exit, missing output and strict-validator failure. It shows only the
validated record before cleanup. Child stderr and shell signal diagnostics are
suppressed. No raw redirected output is printed. There is one copy/paste box and
no clipboard trial or install/restore box.

in our available source before that handoff; original-source analysis and
synthetic controls give stronger evidence here than decompiling macOS.
